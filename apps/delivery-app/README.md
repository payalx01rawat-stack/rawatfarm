# FarmMitra Delivery App

Standalone mobile-first Next.js delivery partner app.

Run from the repository root:

```powershell
npm.cmd run dev --workspace @farmmitra/delivery-web
```

The app runs on `http://localhost:3004` and uses the existing FarmMitra API on port `4000`. See [docs/farmmitra-delivery.md](../../docs/farmmitra-delivery.md) for the local workflow and API contract.
